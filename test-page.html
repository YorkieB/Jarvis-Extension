About Comet Extension

Comet is an advanced browser extension that uses accessibility tree perception to understand web page structure. It combines local heuristics with optional AI API integration to provide hybrid inference capabilities.

The extension features agentic execution for multi-step task chaining, allowing users to automate complex workflows with natural language commands. The contextual sidecar UI provides an intuitive interface for interaction.

Key Features

  • Accessibility Tree Perception
  • Hybrid Inference System
  • Multi-step Task Execution
  • Deep Research Capabilities
  • Contextual Sidecar Interface
