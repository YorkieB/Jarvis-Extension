# Comet Browser Extension 🌟

**AI-Powered Browser Assistant with Accessibility Tree Perception and Hybrid Inference**

Comet is an advanced browser extension that brings intelligent automation to your browsing experience. It uses accessibility tree perception to understand web pages and hybrid inference to execute complex multi-step tasks through an intuitive sidecar UI.

## 🚀 Key Features

- **🌳 Accessibility Tree Perception** - Deep semantic understanding of page structure
- **🤖 Hybrid Inference** - Local heuristics + optional AI API integration
- **⚡ Agentic Execution** - Multi-step task chaining and autonomous execution
- **🔬 Deep Research** - Contextual analysis and insights
- **🎨 Sidecar UI** - Beautiful on-page interface (toggle with `Ctrl+Shift+Space`)

## 📦 Quick Start

1. Clone the repository
2. Load in Chrome/Edge: `chrome://extensions/` → "Load unpacked" → select folder
3. Click the extension icon or press `Ctrl+Shift+Space` on any page
4. Try commands like:
   - "Search for machine learning"
   - "Click the Sign In button"
   - "Research this page content"
